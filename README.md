Official Web Application for **Maurya Technical Private Limited** (Alambagh, Lucknow).
Government Registered Design Service Provider & Training Institute.

1. **Web Design** (Python Web Design, HTML5, CSS3, JavaScript, Bootstrap 5, Django)
2. **Machine Design** (Engineering Drawing, AutoCAD, SolidWorks, CATIA, 3D Modeling, 2D Drafting, Machine Components & Assembly, Mechanical Design Basics)
3. **Circuit Design** (Basic Electronics, Electrical Circuit Basics, PCB Design, Circuit Simulation, Arduino, Proteus, KiCad / EasyEDA)
4. **Building Design** (Architectural Drawing, AutoCAD, 2D Floor Plan, 3D Building Modeling, Revit, SketchUp, Building Planning, Structural Drawing Basics)
5. **Interior Design** (Space Planning, Furniture Layout, AutoCAD, SketchUp, 3D Interior Modeling, V-Ray / Rendering, Material & Color Selection, Lighting Design)
6. **Textile Design** (Textile Designing Basics, Fabric Design, Pattern Making, Surface Design, Digital Textile Printing, Photoshop, CorelDRAW, Color & Pattern Development)
7. **Fashion Design** (Fashion Illustration, Garment Designing, Pattern Making, Draping, Textile & Fabric Knowledge, CorelDRAW / Photoshop, Fashion CAD, Apparel Design)
